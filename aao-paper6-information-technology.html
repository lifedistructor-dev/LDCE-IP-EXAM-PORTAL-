Definition વ્યાખ્યા

Paper VI (Information Technology) is a fully practical, 100-mark, 3-hour paper in the AAO LDCE exam testing MS Word, MS Excel, MS PowerPoint, and basic computer/internet knowledge — no books allowed.

Probable Q: Is Paper VI open-book or closed-book? પેપર VI ઓપન-બુક છે કે નહીં? → Closed book — "WITHOUT BOOKS" 🔴

📝 Exam Pattern Comparison પરીક્ષા પેટર્ન સરખામણી

▼

2018 Pattern 🔴

  • Part A: 30 marks (15 MCQs × 2 marks)
  • Part B: 70 marks (practical)
  • MCQ: 1 mark correct answer + 1 mark for typing in Word (Font size 14)
  • 3 files: A (Word), B (Excel), C (PPT) — named by Roll Number

2022 Pattern 🔴

  • Part A: 15 MCQs × 2 marks = 30 marks, no negative marking
  • Part B: 3 questions — Word (20), Excel (30), PPT (20) = 70 marks
  • MCQ answers reproduced fully in MS Word
  • Pen drive provided if required; extra time for printout
🧠 Mnemonic: "30+70=100" → Part A always 30 marks, Part B always 70 marks, total 100 — pattern is consistent across years.
Probable Q: Total marks and duration of Paper VI? → 100 marks, 3 hours 🔴

📋 Key Instructions મુખ્ય સૂચનાઓ

Important Rules 🔴
  • All questions compulsory
  • No negative marking (2022 pattern) 🟠

  • Files must be saved/printed on A4 sheets
  • Extra time given beyond 3 hours for printout & submission, if required

💻 MCQ Concepts — Computer Basics કમ્પ્યુટર મૂળભૂત

▼
Q: Which is an input device? → Keyboard (Monitor/CPU/Printer are not input) 🔴
Q: Which is NOT an application software? → Windows 7 (it's an OS; WordPad/Photoshop/Excel are applications) 🟠
Q: Services provided by Windows OS: → All of the above (File mgmt, Hardware mgmt, User Interface)
Q: Renaming a file/document: → Right-click icon → Rename from shortcut menu 🟠
Q: Deleted file/document — which is true? → Sent to Recycle Bin, CAN be restored 🔴
Q: Maximize a reduced window: → Either double-click top bar OR click maximize icon (both)
🧠 Mnemonic: "OS Manages, App Does" → OS (Windows) = File+Hardware+UI management; Application = does specific tasks (Word, Excel, Photoshop).

📄 MCQ Concepts — MS Word એમએસ વર્ડ

▼
Q: New footnotes are created via which menu? → Insert 🔴
Q: Menu to cut, copy, paste: → Edit
Q: "Ctrl+Home" in MS Word: → Moves cursor to beginning of the document 🔴
Q: By default, Footers print on: → All Pages
Q: Changing space between two lines — which menu? → Paragraph 🟠
Q: Portrait & Landscape are types of: → Orientation 🔴
Q: Using the Undo button: → Removes new text, restores original text 🟠
🧠 Mnemonic: "Insert-Foot, Paragraph-Space, Home-Start" → Footnotes via Insert, line spacing via Paragraph, Ctrl+Home → document start.

📊 MCQ Concepts — MS Excel એમએસ એક્સેલ

▼
Q: All formulas in Excel start with: → = (equals sign) 🔴
Q: SUM, AVERAGE, MIN, MAX are examples of: → Functions 🔴
Q: What displays the contents of the active cell? → Formula bar 🟠
Q: Advantage of using a spreadsheet: → All of the above (auto-calc, auto-update, flexibility)
Q: To save edited sheet without losing the original: → Save As 🔴
Q: To drag a selected data range to another worksheet in the same workbook: → Alt key (hold Alt while dragging to switch sheet tabs)
Q: Button to add up a series of numbers: → Auto Sum 🔴
🧠 Mnemonic: "= Starts It All" → every Excel formula/function begins with "=". "Alt-Drag-Switch" → Alt key while dragging moves data across worksheet tabs.
Probable Q: What appears in the Name Box vs Formula Bar? → Name Box shows cell reference; Formula Bar shows cell content/formula 🟡

🎞️ MCQ Concepts — MS PowerPoint એમએસ પાવરપોઈન્ટ

▼
Q: Animation schemes can be applied to: → Selected slide(s) (or as specified by user selection)
Q: Key to view slide show: → F5 🔴
Q: PowerPoint presentation file extension: → .ppt 🔴
Q: Effect used to replace one slide with another: → Slide Transition 🟠
Q: How to put a chart in a presentation: → Insert → Chart
🧠 Mnemonic: "F5 = Full Show" → F5 starts the slideshow from beginning; "Transition ≠ Animation" → Transition = between slides, Animation = within a slide's objects.
Probable Q: Difference between Slide Transition and Animation? → Transition changes between slides; Animation moves objects within a slide 🟡

🌐 MCQ Concepts — Internet & Email ઇન્ટરનેટ અને ઈમેલ

▼
Q: URL stands for: → Uniform Resource Locator 🔴
Q: Computer receiving info from a server on the Internet is known as: → Downloading 🟠
Q: Which is a correct email address? → rajesh@abc.com (needs domain after @) 🔴
Q: Option to save an unfinished email without sending: → Save as Draft
Q: Mail sent, "delivery failed" message — likely reason: → Email address is wrong 🟠
🧠 Mnemonic: "URL = Address of Web" → Uniform Resource Locator; "Down = Server→You" → downloading is receiving FROM server.

🛠️ Part B — Practical Question Patterns પ્રેક્ટિકલ પ્રશ્નનો પ્રકાર

▼
MS Word Question Pattern (20 marks) 🔴
  • Reproduce/type a given paragraph or letter with exact formatting (bold, underline, strikethrough, bullets, numbering)
  • Font size/style specified (e.g. size 12, Times New Roman)
  • Line spacing (e.g. 1.5)
  • Merge multiple tables into a single table with alignment
  • Justified alignment for body text; Left alignment for address/subject/sender
  • Page numbering in footer, specific format (e.g. "Scroll")
  • Word Count to be typed at the end
MS Excel Question Pattern (30 marks) 🔴
  • Build a table exactly as shown, with given headers/data
  • Calculate values using formulas (Totals, Percentages, computed columns)
  • Write the actual formula in a specified cell (not just the value)
  • Merge & Center cells for headings
  • Insert a Chart with title and data labels
  • Format table exactly as shown (borders, alignment)
MS PowerPoint Question Pattern (20 marks) 🔴
  • Create slide(s) with specified background, title, font size/style
  • Apply specific formatting: italics, underline, alignment, bullets (numeric)
  • Apply text effects like Double Strikethrough
  • Insert a Table in a slide with chart-style formatting and data labels
Typical Excel Formula Types Seen 🟠
Column TypeFormula Logic
Total (row-wise sum)=SUM(range) e.g. Net Saving = A+B−C
Total (column-wise sum)=SUM(column range)
Percentage of total=(part/whole)*100
Commission-type calc=((E−D)*20)/1000 style nested formula
Projected increase=C*5% (percentage multiplication)
🧠 Mnemonic: "Exact-as-Shown" → the single biggest scoring rule across all 3 practicals: match formatting EXACTLY as given in the question, not just get the right content.
Probable Q: What is commonly asked to be typed at the end of a Word practical answer? → Word Count 🔴
